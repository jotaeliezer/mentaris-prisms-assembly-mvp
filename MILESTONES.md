# Milestones

Milestones are the odd feats. They are not the belt's basic goals, and there is not one for each fabrication. A milestone is granted once. The same top toast used for tutorial lines names it.

A saved flight keeps the ones already earned. Launching a new flight starts the list over.

| Id | Toast | How it happens |
| --- | --- | --- |
| star-halo | Halo | Fly through a layer star's halo. That pass also shakes one dust mote loose. |
| alien-break | First wreck | Break an alien that left the lair. |
| alien-part | Strange cargo | Have any alien part in the hold. |
| core-cannon | Heavy hand | Fire the core cannon. |
| layer-far | Thin belt | Reach a layer at least three away from the arrival. |
| full-ore | Whole belt | Carry Pale, Slate, Amber, Virid, and Glint at the same time. |
| low-repair | Held together | Use a repair patch while the hull is under 20. |
| fast | Past the line | Get the ship moving faster than 500. |
| comet | Caught the tail | Pick up comet dust. |
| stronghold | Opened the ruin | Fly into an abandoned stronghold and take what it spills. |
| wall | First wall | Place a wall. |
| star-rise | Dawn watch | Be in flight when the main star goes from down to up. |
| quiet-debris | Soft through scrap | Fly through a debris field while quiet running is on. |
| golem-lived | Stood the charge | Take a golem's charge and still have hull left. |
